# ADR 0007: WP 1.2 IPC schema

Status: accepted, 2026-09-08. Covers `crates/app`, `packages/ipc`, and the
desktop shell's use of the bindings.

## One schema, generated bindings, a guard that fails when stale

Every command and event is declared once in `crates/app::ipc_builder`
with `tauri-specta`. The whole contract from design 6.4 is there:
`open_document`, `save_document`, `convert_document_to_utf8`, `watch`,
`unwatch`, `merge3`, `snapshot`, `list_snapshots`, `read_snapshot`,
`block_diff`, `list_dir`, `search`, and the `external_change` event.
The ones later work packages implement are stubs that return the
`not_implemented` error kind, so the frontend can call any of them
today and get a typed refusal rather than an unknown-command failure,
and the request and response types for them are fixed now
(`crates/core/src/types.rs`).

The TypeScript lands in `packages/ipc/src/bindings.ts`, exported by the
app at every debug start and by `cargo run -p mdreader-app --bin
export-bindings`. A unit test in `crates/app` exports to a temporary
file and compares it with the committed one, so `cargo test` fails
whenever the contract changed and the bindings were not regenerated.
Biome does not lint the generated file.

## Numbers

specta refuses to export 64-bit integers, since JavaScript numbers lose
precision past 2^53. Byte lengths and millisecond timestamps stay `u64`
in Rust and carry `#[specta(type = specta_typescript::Number)]`, which
exports them as `number`; a file over 8 PB or a date past the year
285,000 would be the first to notice. `f64` was rejected because it
exports as `number | null`, which every consumer would have to unwrap.

## Results and errors

Commands return `Result<T, Error>`; the generated functions resolve to
`{ status: "ok", data } | { status: "error", error }` and the error is
the tagged enum from WP 1.1, so the shell branches on `kind` for the
merge path (`hash_mismatch`) and the conversion banner
(`read_only_encoding`). `packages/ipc` adds `Result`, `Commands`,
`Events`, and `unwrap` for callers that prefer exceptions.

## The fake implements the same interface

`packages/ipc/src/fake.ts` is an in-memory `Commands` with the same
error kinds and the same rules as the core: stale hash refuses, missing
file recreated, read-only encoding refuses, conversion clears it. It
records every call and can simulate an external write to listeners.
Because it is typed as `Commands`, a change to the contract breaks the
fake at typecheck time, which is what the plan asked of the Playwright
fake. The shell's tests (WP 1.3) build on it.

## Core takes a dependency on specta

`crates/core` stays free of Tauri types but derives `specta::Type` on
its public types, and names `specta_typescript::Number` for the fields
above. Both are code generation concerns, not runtime ones.
