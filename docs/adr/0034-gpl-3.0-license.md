# ADR 0034: GPL-3.0-only for the repository

Status: accepted, 2026-09-10. Supersedes [ADR 0033](0033-mit-license.md),
which chose MIT earlier the same day.

The repository is licensed under the GNU General Public License, version 3
only, copyright 2026 Victor Zhang. `LICENSE` at the root is the licence
text verbatim from gnu.org; every `package.json` and the Cargo workspace
carry the SPDX identifier `GPL-3.0-only`, so a consumer of any one piece
can read it without the root. The application bundles `LICENSE` beside
`THIRD-PARTY-NOTICES.md` in its resources, because a copyleft licence has
to travel with the binary and not only with the source.

## What changed, and what did not

Nothing was released under MIT. The choice stood for a few hours in one
commit, there are no tags, and the author is the sole copyright holder, so
no consent was needed from anyone to relicense. The move is a change of
mind, not a migration.

The bundled fonts are unaffected: they ship under the SIL Open Font
License and `THIRD-PARTY-NOTICES.md` still records that. `tools/corpus-gen`
still calls a model API, and what the vendor's terms say about that output
is still between the operator and the vendor; this licence remains the
author's grant over what is committed here.

Per-file licence headers were not added. The GPL recommends them and does
not require them; a single `LICENSE` at the root and the SPDX identifier on
every package is the same arrangement ADR 0033 set up, and it is enough for
a repository whose packages are not published separately.

## Why "only" and not "or later"

"Or later" delegates the terms of a future version to its authors. The
repository has one copyright holder, who can relicense at any time by
making a decision like this one; there is nothing to gain from delegating
it in advance.

## What this overrides

ADR 0033 argued for permissive terms on two grounds: that
`packages/markdown` and `packages/editor-core` are libraries in everything
but distribution and might one day be extracted, and that the generated
corpus is more useful as fixtures under a licence anything can take. It
called copyleft "a live option for the application alone". Both points
remain true, and were set aside: the repository is licensed as one work.
A future extraction of one of the packages under different terms is the
author's to make when and if it happens, and is not blocked by this
decision.
