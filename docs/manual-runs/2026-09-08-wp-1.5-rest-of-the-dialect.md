# WP 1.5 by-hand check — the rest of the dialect

Date: 2026-09-08. Build: the packaged frontend running in the real desktop
window under `pnpm tauri dev` — WKWebView, the asset protocol, the OS open
panel, the opener plugin. This is the first by-hand pass on this project
that used the app itself rather than a browser standing in for it, so it
also closes the checks WP 1.4 and WP 1.3 had to leave open.

The document is in the session scratchpad: a frontmatter block, footnotes,
every callout of the GitHub set plus Obsidian aliases and one invented
type, the whitelist's allowed and refused tags, four images (relative,
relative with a dot and a title, remote, inline HTML), a KaTeX block, a
Mermaid fence, a compact `<details>` block, and the leniency cases. Two
real PNGs sit in a `pictures/` subfolder beside it.

## What this pass changed

- **Important and Caution were not visually distinct.** `important` fell
  back to the note blue and `caution` shared the warning amber, which
  defeats the reason both are canonical types. The palette now follows
  GitHub: note blue, tip green, important purple, warning amber, caution
  red. Fixed in both stylesheets, and the editor's callout tint now
  derives from the type's own colour instead of a fixed blue.

## Observed and accepted

- **Refused inline HTML keeps the HTML grammar's syntax colours in Edit
  mode.** `<script>` and `<div>` show with green tag names, from
  `@codemirror/lang-markdown`'s HTML sub-parser, so refused markup is more
  prominent than allowed markup, which is dimmed. Design 5.3's "shown as
  literal text" is about not rendering the element, which holds — the tag
  is inert text and Read mode shows it plainly. Syntax colour in a source
  view is not a rendering. Left as it is; WP 1.9 revisits both palettes.
- **A footnote reference reads as its label in Edit and as its number in
  Read.** Live preview hides syntax but never substitutes text, and the
  number is not in the file. This is the same rule that keeps every other
  construct honest.
- **A ragged table whose delimiter row has fewer columns than its header
  renders as a paragraph**, so its lines run together. That is what
  CommonMark defines and what GitHub does, and design 5.2 says to follow
  CommonMark where it defines the fallback.
