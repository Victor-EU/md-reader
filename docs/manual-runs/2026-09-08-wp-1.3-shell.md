# WP 1.3 by-hand check — the shell on macOS

Date: 2026-09-08. Build: `pnpm tauri dev` (debug), WKWebView, macOS 15.5,
window 1100×760. Files: two scratch documents outside the repo.

Rule 1 of the build plan asks for the work package's scenario checked by
hand. WP 1.3 has no scenario of its own — S1 needs Read mode (WP 1.4) — so
this is the shell's own surface: open, tabs, modes, palette, save.

| Check | Result |
|---|---|
| Empty window | Tab strip empty, toolbar says "No document", no mode looks selected, page invites opening a file |
| Cmd+O, pick a file | Tab `shell-a.md`, breadcrumb ends in the file name, live preview renders, status `11 words · UTF-8 · LF · Saved` |
| Type into the document | Dirty dot on the tab, status turns to `Unsaved changes`, word count settles a moment later |
| Cmd+S | File on disk carries the edit, trailing newline preserved, status `Saved shell-a.md`, dot clears |
| Cmd+O a second file | Two tabs, the new one in front |
| Cmd+P | Both open files listed, file name then shortened directory, first row selected |
| Escape | Palette closes, the tab is unchanged |
| Cmd+1 | Jumps to the first tab |
| Cmd+W | Tab closes, status says which document was closed |
| Cmd+Shift+T | Tab comes back in its old place, with its buffer and its cursor where it was |
| Cmd+Shift+P | 15 commands with shortcuts; Convert to UTF-8, Reopen Closed Tab and Read Mode greyed out |
| Fuzzy filter (`sview`) | `Open a Second View`, matched letters underlined |
| Source mode | Decorations off, status gains `Ln 7, Col 1` |
| Pin (double click a tab) | Tab moves to the front of the strip with its pin mark |

Fixed while checking, before the commit:

- The breadcrumb read right to left (`shell-a.md › scratchpad › …`). The
  `direction: rtl` trick for left-side truncation reverses flex items too;
  it now shows the last four segments with a leading ellipsis and the whole
  path in the tooltip.
- The palette panel stretched to the full height of the window, because the
  scrim is a flex container and its child stretched by default.
- With no document open, the Edit segment of the mode switch looked pressed.
- An untitled document reported `Saved`; it now says `Not saved yet`.
- Palette rows showed the whole parent path; they now show its last two
  segments.

Not checked by hand: dropping a file from Finder onto the window. The DOM
drop path has a test, and the Tauri webview path (`onDragDropEvent` in
`main.ts`) is wired the way the plugin documents, but a real Finder drag
could not be driven from the automation used for the rest of this run.
