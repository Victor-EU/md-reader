# By hand: WP 2.7, large files and the window onto a document

2026-09-09. Against the installed release build — `pnpm tauri build
--bundles app`, copied to `/Applications/MD Reader.app` — driven with
real keystrokes and a real mouse, with screenshots of the window.

## The setup

Four files in a scratch folder:

- `long.md`, **12 MB**: 10,919 sections of generated prose, with a
  TypeScript fence every seventh, a table every eleventh, a callout every
  thirteenth, and two footnotes — one referred to in the opening
  paragraph and again in the last section, one only at the end. Over
  design 8's editing ceiling and under its opening one.
- `small.md`, 82 bytes, so that every refusal can be shown to be about
  the file and not about the app.
- `huge.md`, **120 MB**, over the opening ceiling.
- `latin.md`, a WINDOWS-1252 file, for the other banner.

`session.json` was removed first, so the run starts from an empty window,
and both it and `settings.json` were put back afterwards.

## The five it found

Each is described in ADR 0025 and each has a test that fails without its
fix.

1. **A hidden block has no box.** A folded-away comment measures at
   `offsetTop` zero, which put its neighbours at plus and minus a hundred
   thousand pixels and, through the calibration, every block of that kind
   after them. A four hundred kilobyte document ended up on a
   thirty-three million pixel scrollbar.
2. **The outline panel looked empty.** A flex column shrinks its children
   rather than overflowing: ten thousand rows became six pixels each.
3. **`Home` stopped part way.** WebKit animates keyboard scrolling and
   any write to `scrollTop` cancels it; the measurement pass wrote one
   almost every frame.
4. **Unfolding brought nothing back**, because the window is filled from
   its ends and a fold empties the middle.
5. **Headings were guessed at half their height**, which left the
   document six percent short and `End` landing at 43%.

## What was seen and left alone

- `End` lands close to the end rather than on it, and each press gets
  closer as the blocks it passes are measured. Anchors — the outline, a
  heading link, a footnote — are exact.
- The outline panel builds a row per heading. Ten thousand buttons is a
  lot of panel, but it is the page this package virtualizes.
